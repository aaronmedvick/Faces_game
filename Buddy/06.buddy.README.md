# Office Buddy — line bank (06.buddy)

Every line Aaron can say, with its category. This is the editable source of truth.
Edit the CSV in a spreadsheet or the JSON directly, then run `inject.py` to rebuild `buddy.html`.

## Files
- `06.buddy.lines.json` — array of `{id, category, chip, badge, text}`
- `06.buddy.lines.csv` — same data, spreadsheet-friendly

## Adding a line

Add a row with an existing `category` key (or invent a new one — if new, also add a chip
in `CATS` and a badge in `CAT_LABEL` inside buddy.html). `id` is just for your reference.
Avoid straight double-quotes inside `text` (use single quotes) so the JS injection stays clean.

# Gut Check question packs

**To add a pack: add a file named `09.gutcheck.pack-NN.txt` (or `.json`) to `Data/`. That's it.**

A file is a pack. A pack has categories. Categories have questions.

    # pack: Pack 3

    ## Animals
    cute | are | penguins | 88
    lazy | are | sloths | 85

    ## Food & drink
    greasy | is | pizza | 65

- `## Name` starts a category. Questions go under it, one per line.
- Question line: `adjective | is or are | the thing | typical answer 0-100`. Reads as "How *adjective* *is/are* *the thing*?"
- The 4th field is optional (default 50). It only steers the practice bots.
- `# pack: Name` sets the pack name (otherwise it comes from the file name). Other `#` lines and blank lines are ignored.
- Duplicates across files are dropped. Files starting with `_` are ignored.
- In the lobby the host can switch whole packs, or single categories, on and off.

Adding a question to an existing pack: open the file on GitHub, tap the pencil, add a line, commit.

## JSON also works

    { "pack": "Pack 3",
      "categories": { "Animals": [ {"adj":"cute","verb":"are","subject":"penguins","c":88}, "lazy | are | sloths | 85" ] } }

## How the game finds files

GitHub Pages can't list the data folder by itself, so the game uses two methods:
1. `09.gutcheck.index.json`, rebuilt automatically by the GitHub Action (`.github/workflows/data-manifests.yml`) on every push.
2. A direct folder listing from GitHub's API, so a new file appears even before the index updates.

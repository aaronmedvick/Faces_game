# Kindred question packs

Add a file named `07.kindred.pack-NN.json` to `data/` and the game loads it. No code changes, no list to edit.
Name them `07.kindred.pack-02.json`, `pack-03`, and so on. They load in alphabetical order.

## The file
```json
{
  "pack": "Pack 2",
  "on": true,
  "categories": [
    {
      "name": "Food & Drink",
      "d": 1,
      "questions": [
        { "q": "Breakfast for dinner?", "o": ["Yes please", "Absolutely not"] },
        { "q": "How adventurous is your eating?", "lo": "Same five meals", "hi": "I'll try anything" },
        { "t": "rank", "q": "Rank these, best first.", "o": ["Tacos", "Pasta", "Sushi"] }
      ]
    }
  ]
}
```
Copy `07.kindred.pack-01.json` to start.

## What you can leave out
- **`t` (type):** worked out for you. `lo` and `hi` means a 1-7 slider. Two options is a this-or-that. Three to six options is pick-one. The only time you write `t` is `"t": "rank"` (order three items).
- **`id`:** made for you from the question text.
- **`d` (depth):** 1 light, 2 people, 3 deep. Set it on the question, or once on the category, or once on the pack. If nothing is set it is 2. Games start at 1 and finish at 3.

## Categories
The host picks which categories to play when opening a room. Two files with the same
category name merge into one category, so Pack 2 can add more "Food & Drink".

## Question types
| what you write | becomes |
|---|---|
| `o` with 2 options | this-or-that |
| `o` with 3 to 6 options | pick one |
| `lo` and `hi` | 1 to 7 slider |
| `"t": "rank"` and `o` with exactly 3 | rank all three |

## Fixing typos
Without an `id`, changing a question's wording makes it a new question (people's old
answers to it stop counting). To fix a typo and keep the history, add an `id` of your own
to that question and never change it again, like `"id": "food-pizza"`.

## Checking your file
Open the game. The footer shows how many questions and packs loaded. If anything was
skipped it shows a warning; tap it to see which file, which category and which question.

## How it finds files
The game lists `data/` through GitHub, so a new file shows up right away. If that is
unavailable it uses `07.kindred.manifest.json` (kept current by the GitHub Action in
`.github/workflows/kindred-manifest.yml`), and finally a built-in copy of Pack 1.

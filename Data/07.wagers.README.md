# Wits & Wagers packs

**Add a file named `07.wagers.pack-NN.json` to `data/` and push. The game finds it and loads it — nothing else to edit.**
Files starting with `_` are ignored. Questions with the same text in two packs are only used once.

## Pack format (either style, or mix them)
```json
{
  "pack": "Pack 2 — Music",
  "questions": [
    {"cat":"music","type":"year","level":3,"q":"In what year was Elvis's first #1 hit released?","a":1956}
  ]
}
```
```json
{
  "pack": "Pack 3 — Space",
  "level": 3,
  "categories": {
    "planets": [ {"q":"How many Earth days is a Mars year (whole days)?","a":687} ],
    "missions": [ {"q":"In what year did Voyager 1 launch?","a":1977,"type":"year"} ]
  }
}
```
| field   | where | notes |
|---------|-------|-------|
| `cat`   | question (or pack-level, or the key under `categories`) | category name, any text |
| `level` | question or pack-level default | 1 Easy · 2 Medium · 3 Hard · 4 Archaic |
| `q`     | question | say the unit in the text |
| `a`     | question | exact whole number ≥ 0 (BC years positive: `44` = 44 BC) |
| `type`  | question or pack-level default | `count` (default) · `year` (no commas) · `measure` (shows `unit`) |
| `unit`  | question | `ft`, `m`, `km`, `°F`… for `measure` |

## Checking
Packs need whole-number answers and levels 1 to 4; bad questions are skipped and duplicates are ignored. The GitHub Action refreshes `07.wagers.manifest.json`.
The included GitHub Action runs this automatically on every push.

## How the game finds packs
1. Lists `data/` through the GitHub API (so a new file works right away).
2. If that's blocked or rate-limited, uses `07.wagers.manifest.json`.
3. If both fail, uses 8 built-in questions.
